# Planer

Личный органайзер для Android. Работает без интернета, все данные хранятся на телефоне.

Приложение собрано из универсальных кирпичиков, которые можно настроить под любой план:

| Кирпичик | Что это | Пример |
|---|---|---|
| Привычки | Регулярное действие с расписанием, серией и «минимумом» на тяжёлый день | Код по будням, спина и осанка |
| Трекеры | Любая величина с историей и графиком: число, оценка 1–10, время с таймером, да/нет | Вес, время кода, Faceit |
| Цели | Измеримый результат к сроку с прогнозом по текущему темпу | Вес 73 кг, закрыть кредит |
| Деньги | Расходы и доходы по категориям, копилки и долги со сроком закрытия | Кредит, копилка на права |
| Тренировки | Программы с подходами и повторами, запись тренировки и подсказка, когда усложнять | Тренировка A и B |
| Записи | Итог дня с настроением, обзор недели, заметки | 3 дела за день |
| Сон | Кнопки «Ложусь спать» и «Я проснулся», цель отбоя и подъёма, серия, недосып, напоминание перед отбоем | Отбой в 23:00, подъём в 7:00 |
| Питание | Калории, белок и вода за день, свои блюда в один тап, подсказка по весу для набора, поддержания или снижения | 3000 ккал и 130 г белка |

У каждой записи своя иконка из набора, разбитого по темам. Поверх кирпичиков: экран «Сегодня», напоминания, отчёт недели, шаблоны для старта и перенос всех данных одним файлом.

## Установка на телефон

1. Открой на телефоне [последний релиз](https://github.com/smesherlu23-cmd/Planer/releases/latest) и скачай `planer.apk`.
   Свежая сборка из незаслитой ветки лежит в [предварительной сборке](https://github.com/smesherlu23-cmd/Planer/releases/tag/preview).
2. Открой файл. Android попросит разрешить установку из браузера или файлового менеджера: разреши.
3. Новые версии ставятся поверх старой, данные сохраняются.

При первом запуске можно выбрать шаблон «Мой план» или чистый лист. Потом всё меняется как угодно.

## Перенос данных

«Ещё → Настройки и данные»:

- **Сохранить в файл** или **Отправить файл**: все данные в одном JSON.
- **Загрузить из файла**: заменяет текущие данные содержимым файла. Перед заменой приложение сохраняет копию, и её можно вернуть кнопкой «Вернуть данные до импорта».

Формат файла: `{"app": "planer", "format": 1, "schema": 2, "exportedAt": ..., "tables": {"habits": [...], ...}}`, по одному массиву строк на каждую таблицу базы.

## Подпись APK

Чтобы новая версия ставилась поверх старой, все сборки подписаны одним ключом. Сейчас это общий ключ `android/app/planer-dev.jks` прямо в репозитории: просто и работает сразу, но любой, у кого есть доступ к репозиторию, может подписать им свой APK.

Чтобы перейти на свой секретный ключ, добавь в Settings → Secrets and variables → Actions секреты
`PLANER_KEYSTORE_BASE64` (файл ключа в base64), `PLANER_KEYSTORE_PASSWORD`, `PLANER_KEY_ALIAS`, `PLANER_KEY_PASSWORD`.
Сборка сама начнёт ими пользоваться. При смене ключа один раз нужно сохранить данные в файл, удалить приложение, поставить новое и загрузить файл.

## Разработка

```bash
flutter pub get
dart run build_runner build   # после изменения таблиц в lib/data/database.dart
flutter analyze
flutter test
```

Скриншоты всех экранов для проверки глазами (в git не попадают):

```bash
flutter test --dart-define=SCREENSHOTS=true --update-goldens test/ui_test.dart
# картинки в test/screens/
```

Каждый push собирает APK в GitHub Actions: из `main` получается релиз, из других веток обновляется предварительная сборка.

### Устройство кода

- `lib/data/` база (drift + SQLite), запросы, шаблоны, экспорт и импорт
- `lib/logic/` чистые расчёты: серии, прогнозы, долги, отчёт недели
- `lib/services/notifications.dart` локальные напоминания
- `lib/ui/` экраны

День хранится числом вида `20261108`, дни недели маской (бит 0 = понедельник), время напоминания в минутах от полуночи.
